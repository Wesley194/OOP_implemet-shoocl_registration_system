# 🏫 School Registration System

這是一個基於 **Java** 與 **SQLite** 開發的物件導向 (OOP) 專案。系統模擬了真實大學的選課機制，包含完整的圖形化介面 (GUI)、資料庫持久化儲存，以及防呆機制。

## ✨ 核心功能 (Features)

系統分為「教師」與「學生」兩種使用者身分，並具備以下功能：

### 👨‍🏫 教師 (Teacher)

- **登入系統**：獨立的教師儀表板。
- **課程管理**：可開設新課程，系統會自動綁定授課教師並將紀錄寫入資料庫。
- **登記成績**：可查看所開課程的「修課學生名單」，並為學生登記或修改期末成績。

### 🎓 學生 (Student)

- **登入系統**：專屬的學生課表與選課介面。
- **瀏覽課程**：可查看全校所有已開設的課程清單與上課時間。
- **進行選課**：具備完整的防呆驗證機制：
  - 🚫 **衝堂檢查**：自動比對上課時間 (TimeSlot)，防止時間衝突。
  - 🚫 **重複選課**：防止同一門課被重複選修。
  - 🚫 **人數限制**：當課程人數已滿時拒絕加選。
- **個人課表與成績單**：隨時查看已選課程、上課時間，以及教師已登記的成績與 GPA 結算。

## 🛠️ 技術架構 (Tech Stack)

- **程式語言**：Java (物件導向設計：封裝、繼承、多型)
- **圖形介面**：Java Swing (`MainGUI`)
- **關聯式資料庫**：SQLite (透過 JDBC 連線)

## 🗄️ 資料庫設計 (Database Schema)

系統底層使用 4 張關聯表來維護資料：

| 表格名稱      | 說明                                    | 關聯性                                   |
| ------------- | --------------------------------------- | ---------------------------------------- |
| `students`    | 儲存學生基本資料 (學號、姓名、密碼)     | 獨立                                     |
| `teachers`    | 儲存教師基本資料 (員工編號、姓名、密碼) | 獨立                                     |
| `courses`     | 儲存課程資訊 (代碼、學分、上課時間)     | `teacher_id` (Foreign Key)               |
| `enrollments` | 儲存選課紀錄與成績 (多對多中介表)       | `student_id`, `course_id` (Composite PK) |

## 🚀 如何執行 (Getting Started)

### 1. 環境準備

請確保你的專案中已經引入了 **SQLite JDBC Driver** (`sqlite-jdbc.jar`)。

### 2. 生成測試資料 (可選)

首次執行時，建議先執行測試腳本，系統會自動建立乾淨的資料庫，並隨機生成 15 位學生、5 位教授以及 5 門課程與隨機選課紀錄。

- 執行檔案：`DatabaseTester.java`

### 3. 啟動系統

- **圖形化介面 (GUI)**：執行 `MainGUI.java` (推薦)

### 📝 測試帳號提示

若有執行 `DatabaseTester`，可使用以下帳號登入：

- **教授帳號**：`T001` ~ `T005` (密碼統一為：`1234`)
- **學生帳號**：`B001` ~ `B015` (密碼統一為：`0000`)
